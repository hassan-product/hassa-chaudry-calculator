Key states: default, hover, pressed, focused

Hover changes the label colour as well as the fill. Pressed adds an inset shadow. Focus adds a ring outside the key. Hover applies only on devices with hover, so nothing stays highlighted after a tap. The "Change sign" tooltip is shown on the hovered +/− key.

Also:

  • --size-key-gap 0.75rem
  • --size-key-min 2.75rem (44px)
  • --size-key-height 4.5rem with legends, 3.5rem without. On a short window it shrinks toward the minimum, and the page scrolls.
  • --size-rail-min 30rem (480px)
  • --size-narrow-max 40rem
  • --size-gutter 1rem, or the safe-area inset if larger
  • Focus ring 3px with a 2px offset
  • --key-operator-glyph-scale 1.35: the ÷ × − + = glyphs are drawn small in system fonts, so they are scaled to match the digits' ink height. The font size stays 24px, so the display is still the largest type.
  • Pressed: inset 0 2px 4px rgba(0,0,0,.25)
  • The 900px breakpoint is a constant in the CSS, because variables cannot be used in media queries.
